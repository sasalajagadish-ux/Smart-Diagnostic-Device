# Contributing to Smart Diagnostic Device (SDD)

Thank you for your interest in contributing! 🎉

## 📋 How to Contribute

1. **Fork** the repository
2. **Create a branch** → `git checkout -b feature/your-feature-name`
3. **Make your changes** and commit → `git commit -m "feat: add your feature"`
4. **Push** → `git push origin feature/your-feature-name`
5. **Open a Pull Request** with a clear description

## 🐛 Reporting Issues

- Use GitHub Issues to report bugs
- Include hardware setup details, firmware version, and error logs

## 💡 Coding Standards

- Follow **PlatformIO** project structure for firmware
- Comment all hardware-interfacing code clearly
- Add unit tests for new diagnostic routines

## ⚠️ Safety First

All contributions involving 230V AC hardware interfaces **must** include proper isolation and safety documentation.
